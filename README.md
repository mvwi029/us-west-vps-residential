## 美西 VPS 的线路等级，以及 SixtyNet 标了哪一条

先给判断工具。业内对中国大陆方向的回程线路有个大致排序：163 骨干 < 4837 < 9929 < CN2 GIA。价格基本也按这个顺序走。

普通 163 骨干和联通 4837 是各自运营商的公共出口，晚高峰被挤爆的多是这两类，表现就是白天延迟 150ms，晚上八点以后飙到 300ms 以上甚至丢包。9929 是联通的高端商业承载网（CUG，AS9929），优先级更高、拥堵更少，属于“多花一点钱、体验明显上一档”的位置。CN2 GIA 是电信的精品线路，AS4809，跑 traceroute 时看到 `59.43.x.x` 这些节点基本就能确认。移动侧的 CMIN2 是 AS58807，是移动自己的国际精品网。

## 住宅 IP 能干什么，以及它关掉的两个端口

住宅 IP 的价值在于“看起来像个真人”。数据中心 IP 段被各大平台标记了十几年，做社交媒体多账号、爬虫、SEO 监测、广告验证这类活，用机房 IP 很容易刚注册就被风控。住宅 IP 分配的是运营商宽带地址段，被判定为普通家庭用户，这是 SixtyNet 整个产品线的立足点。

但官网在 Residential 系列每一款的说明里都写了一句话：**由于 IP 风控原因，住宅 IP 产品不开放 80 和 443 端口。**

这句话的后果很直接：你不能在这类机器上跑任何对外提供 HTTP/HTTPS 服务的程序。WordPress、静态站、API 服务、反代，全都做不了。想建站只能用非标准端口访问，实际使用中体验很差，绝大多数建站场景等于直接排除。

所以“住宅 IP + 建站”这个组合在 SixtyNet 这里不成立，这是很多人看到“住宅 IP VPS”第一反应会踩的坑。

AS9929 那两款住宅 IP 的限制更严一层。它们默认拒绝所有外部探测和扫描，不配置白名单或端口转发就连不进去。这是安全设计，代价是上手成本：开机之后第一件事是配访问规则，不是直接 SSH 上去。

## 下单前要确认的五件事

**流量周期官网没写清楚。** 5TB 是每月还是每年，产品页上没有明确标注。如果是每年 5TB，那平均每月只有 400G 出头，对建站来说就紧张了。这一条必须在下单前问清楚，也是我认为最该确认的一项。

**流量是单向还是双向计费。** 官网同样没有说明。行业内两种做法都有，双向计费意味着上传下载都算，跑备份、传视频这类操作消耗会比预期快一倍。

**年付制意味着试错成本高。** 全系产品按年付计价，没有看到月付选项。买错一次就是一年的钱。如果只是想验证线路质量，先确认商家是否支持短期退款，以及退款是原路退回还是退到余额（AS9929 住宅款明确只退余额）。

**住宅 IP 的 80/443 端口限制不可协商。** 这是产品设计，不是配置问题。买之前先确认你的用途不需要这两个端口。

**AS9929 住宅款的访问控制要先规划。** 默认拒绝外部扫描意味着开机后连不上是正常现象，得先配好白名单或端口转发。不熟悉这套流程的话，第一小时会很懵。
